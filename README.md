# Ant-Captcha 🐜

**Ant-Captcha is a CAPTCHA-solving toolkit for robotic process automation (RPA).**

让 RPA 机器人像蚂蚁一样勤劳地翻越验证码这道坎。

## 📖 简介

Ant-Captcha 是一套面向**机器人流程自动化（RPA）**场景的验证码（CAPTCHA）识别与处理工具集。

在实际的 RPA 业务流程中，登录、查询、提交等环节常常会遇到各类验证码拦截，导致自动化流程中断。Ant-Captcha 的目标是提供一套开箱即用的解决方案，帮助 RPA 流程平滑地通过验证码环节，减少人工介入。

> ⚠️ **声明**：本项目仅供学习研究与合法的 RPA 自动化场景使用，请遵守目标网站的条款与相关法律法规。

## ✨ 特性规划（Roadmap）

> 仓库刚刚初始化，以下为规划中的能力，欢迎参与共建。

- [ ] **滑块验证码（Slider CAPTCHA）**：轨迹模拟、缺口检测
- [ ] **点选验证码（Click CAPTCHA）**：按语义词选图片
- [ ] **图形验证码（Image CAPTCHA）**：OCR / 深度学习识别
- [ ] **行为检测规避**：模拟人类鼠标轨迹与点击节奏
- [ ] **多后端支持**：本地模型 + 云端打码平台（如 2Captcha、Anti-Captcha）
- [ ] **RPA 框架集成**：适配 Playwright / Selenium / 主流 RPA 平台
- [ ] **简洁的 API**：一行代码接入现有流程
